## New: find servers by mod, AI, country and more
The **All servers** tab has new ways to find a server:
- **Search by mod.** Type "Terje", "Expansion" or any mod name and you get every server running it, even when the server's name doesn't say so. The server shows which of its mods matched.
- **Has AI.** Tick it to see only servers with AI: ones running an AI mod (Expansion AI and others) or with AI in their name.
- **Country.** Every server shows where it's hosted (US, DE, AU…). Filter by country or a whole continent, like Europe or North America.
- **Player count.** Has players (the default), 1–14, 15–49 or 50+ players.
- **PvE or PvP.** "PvE only", or everything else. DayZ has no PvE setting, so this goes by what each server calls itself.

## New: clean up mods you don't use
- **Remove its mods.** Done with a server? Click **Remove its mods…** above its mod list. Only the mods that server alone uses are removed; anything another server, favorite or preset needs is kept.
- **Not played in 30+ days.** The **MODS** page now shows when you last played with each mod, and points out the ones you haven't used in a month, with the space they take. **Show them**, then **Remove these** clears them in one go. (Tracking starts with this version, so nothing counts as old for the first 30 days.)
- **Fixed:** "Remove unused" could treat your Favorites' and Recent servers' mods as unused if you hadn't opened those tabs yet. Saved servers now remember their mods.

## Server admins
Run **update-agent.bat** as administrator. With the Steam key set, the agent now adds each server's country (it downloads DB-IP's free country database once a month into the new `geoip` folder) and collects modded servers' mod lists for mod search, gently: at most 40 servers a second, every 30 minutes. `agent.log` shows "Mod search: mod lists from N of M modded servers". Both can be turned off in `agent.jsonc` (`"CountryLookup"`, `"ModSearch"`).

Country data: IP Geolocation by [DB-IP](https://db-ip.com) (CC BY 4.0).

## New: Friends tab
See which of your Steam friends are playing DayZ, and where:
- **PLAYING NOW:** the servers your friends are on, with their names. Click one to see the server and **JOIN SERVER**.
- **Seen recently:** servers the launcher has seen your friends on in the last 30 days.
- Any server your friends are on says **"Friends here: …"** under its name.
- Friends in DayZ's menu (not on a server) are listed separately.

This doesn't make Steam show you as "Playing DayZ". The lookup goes through the MM server.

**Needs:** your Steam friends list set to public. Friends only show a server if their game details are public. Both are Steam's defaults. If yours is private, the tab tells you where to change it.

## New: Mods page
A new **MODS** page next to DAYZ EDITOR:
- **Downloaded:** all your DayZ mods with their size, last update and what uses them (MM servers, your favorites and recent servers, editor presets). **Update all** gets every outdated mod at once.
- **Free up space:** filter to **Not used by anything**, then **Remove unused…**. Removing a mod unsubscribes it in Steam (so it doesn't come back) and deletes its files. Anything a server needs is downloaded again when you join.
- **Steam Workshop:** search the DayZ Workshop, or browse popular, most subscribed, recently updated and newest mods. **Install** downloads a mod and the mods it needs. Paste a Workshop link to jump straight to it.

Browsing doesn't make Steam show you as "Playing DayZ". Installing, updating and removing show it briefly, the same as when you join.

## New: installer
You can now get MM Launcher two ways:
- **MMLauncher-Setup.exe** (recommended): installs it with a Start menu shortcut, an optional desktop shortcut and an uninstaller in Settings > Apps. No admin prompt.
- **MMLauncher.exe**: the portable version, as before. Run it from anywhere.

Both use the same settings, so you can switch any time. Your current launcher keeps updating itself as usual.

## Server admins
Run **update-agent.bat** as administrator. Friends and Workshop search use the Steam Web API key you already set for the server browser; nothing else to change.

## Downloads
- **MMLauncher-Setup.exe**: the launcher for players, installed with shortcuts. Updates itself in one click.
- **MMLauncher.exe**: the same launcher as a single portable file.
- **MMServerAgent.zip**: for MM server admins. See `AGENT-SETUP.txt` inside.

## New: Friends tab
See which of your Steam friends are playing DayZ, and where:
- **PLAYING NOW:** the servers your friends are on, with their names. Click one to see the server and **JOIN SERVER**.
- **Seen recently:** servers the launcher has seen your friends on in the last 30 days.
- Any server your friends are on says **"Friends here: …"** under its name.
- Friends in DayZ's menu (not on a server) are listed separately.

This doesn't make Steam show you as "Playing DayZ". The lookup goes through the MM server.

**Needs:** your Steam friends list set to public. Friends only show a server if their game details are public. Both are Steam's defaults. If yours is private, the tab tells you where to change it.

## Server admins
Run **update-agent.bat** as administrator. The Friends feature uses the Steam Web API key you already set for the server browser; nothing else to change.

## Downloads
- **MMLauncher.exe**: the launcher for players. Updates itself in one click.
- **MMServerAgent.zip**: for MM server admins. See `AGENT-SETUP.txt` inside.
- **SHA256SUMS.txt**: checksums the launcher and agent use to verify updates.

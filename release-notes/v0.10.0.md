## New: server news
MM servers now have a **NEWS** tab next to REQUIRED MODS, with posts from MM staff: wipe dates, events, downtime and changes.
- Servers with news you haven't read show a **NEW** badge in the server list, and open on the NEWS tab.
- Important posts (like wipes and downtime) are highlighted. Posts can include a link, for example to the Discord announcement.

## Changes
- A mod that was deleted or hidden on the Steam Workshop now says **Not on Workshop** instead of "Removed", so it doesn't look like the Remove button on the Mods page.

## Server admins
Run **update-agent.bat** as administrator. The agent then makes a `news` folder next to it with a commented `all.txt` that explains how to write posts. `all.txt` shows on every server; a file named after a server's game port (e.g. `2302.txt`) shows on that server only. Saved changes show up within a minute; no restart needed.

## Downloads
- **MMLauncher-Setup.exe**: the launcher for players, installed with shortcuts. Updates itself in one click.
- **MMLauncher.exe**: the same launcher as a single portable file.
- **MMServerAgent.zip**: for MM server admins. See `AGENT-SETUP.txt` inside.
- **SHA256SUMS.txt**: checksums the launcher and agent use to verify updates.

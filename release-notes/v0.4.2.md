## New: rejoin automatically if DayZ closes
There's a new checkbox under **JOIN SERVER**: **Rejoin automatically if DayZ closes**. It's off until you tick it, and the launcher remembers your choice.

With it on, the launcher keeps an eye on DayZ after starting it. If the game crashes, or you close it to update a mod:
- The launcher pops up with a countdown and a **Cancel** button.
- **If the server is still up:** it updates any changed mods and rejoins after 15 seconds.
- **If the server is restarting:** it waits until the server is back, then waits a random 1–2 minutes so everyone doesn't hit the server at the same moment.
- **Passworded servers:** the password is reused for that session only. It's never saved.
- **If DayZ keeps closing right after it starts:** after three times in a row, auto-rejoin pauses and suggests sending a report to staff.

Note: if a restart only drops you to DayZ's main menu and the game stays open, the launcher can't tell. Close DayZ and it'll take it from there.

## Downloads
- **MMLauncher.exe**: the launcher for players. If you already have it, it updates itself in one click.
- **MMServerAgent.zip**: no agent changes in this release; server admins don't need to update.
- **SHA256SUMS.txt**: checksums the launcher and agent use to verify updates.

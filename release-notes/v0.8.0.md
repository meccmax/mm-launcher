## New: DayZ Editor page
Click **DAYZ EDITOR** at the top of the launcher to start DayZ offline with the DayZ Editor, ready to build.
- CF, Dabs Framework and DayZ-Editor always load first, then your preset's mods, in the order you set.
- **START DAYZ EDITOR** downloads anything missing or outdated through Steam, then starts DayZ. Open the Editor from the main menu.
- **Presets:**
  - Make as many as you like.
  - Add mods you already have, or paste Workshop IDs or links.
  - Change the order with ▲/▼.
- **Import / Export** uses the DayZ launcher's preset files (.html), so presets move freely between the two. A text file of Workshop IDs or links also imports.
- **Shared MM presets:** presets made by MM staff appear automatically, marked "shared by MM". Click **Copy** to make your own version.

## Changed: rejoining, after your feedback
- **JOIN WHEN READY**: when a server is restarting or down, the JOIN SERVER button becomes **JOIN WHEN READY**.
  - Click it and the launcher waits for the server, then joins you automatically (after a short random wait, so not everyone connects in the same second).
  - Still sitting at DayZ's connection screen? It asks first, then closes DayZ and starts it again, connected.
  - You choose it each time, and can cancel any time.
- **"Rejoin automatically if DayZ crashes"** now really means crashes. Logging off or closing DayZ yourself never brings you back in. Thanks Nully!
- A down server now says "Not answering right now" instead of a technical error.

## Server admins
1. Run **update-agent.bat** as administrator. The agent creates an `editor-presets` folder next to it.
2. Export a preset from the DayZ launcher (Mods > Presets > Export) and drop the .html into that folder. Every launcher shows it within a minute, with no restart needed.

## Downloads
- **MMLauncher.exe**: the launcher for players. Updates itself in one click.
- **MMServerAgent.zip**: for MM server admins. See `AGENT-SETUP.txt` inside.
- **SHA256SUMS.txt**: checksums the launcher and agent use to verify updates.

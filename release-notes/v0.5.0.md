## Encrypted connection to the MM servers
The launcher and the MM Server Agent now talk over an encrypted connection (HTTPS), like a bank website. Mod lists and problem reports can't be read or faked on the way.
- The launcher checks each agent's key against the list of official MM agents published on GitHub, so a fake "MM server" can't feed it a mod list.
- Problem reports (crash logs and PC info) are always sent encrypted.
- Nothing to set up for players. The launcher updates itself as usual.

## Server admins
Run **update-agent.bat** as administrator on each server. On first start, the agent makes its own encryption key (`agent-tls.pfx`). Keep that file; it's how launchers recognise the agent.

Then run **check-agent.bat** and send the **"Encryption key fingerprint"** line, with the address and port players use, so it can go in the official list (`trust/agents.jsonc`).

Older launchers keep working until they update. Once everyone is on v0.5.0, set `"AllowPlainHttp": false` in `agent.jsonc` and restart the service, so the agent only accepts encrypted connections.

## Downloads
- **MMLauncher.exe**: the launcher for players. Updates itself in one click.
- **MMServerAgent.zip**: for MM server admins. See `AGENT-SETUP.txt` inside.
- **SHA256SUMS.txt**: checksums the launcher and agent use to verify updates.

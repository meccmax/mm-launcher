## New: repair mods from the MODS page
- Every downloaded mod now has a **Repair** link: it deletes that mod's files and downloads it fresh through Steam (if the download fails, the old copy is put back).
- **Check files** looks at every downloaded mod for missing or broken files. Damaged ones show under the new **Damaged files** filter, with a **Repair** button to fix them all at once.

## New: choose fullscreen or windowed
**Settings > Joining a server > Game display:**
- **Use DayZ's own setting** (default): nothing changes.
- **Fullscreen:** DayZ opens fullscreen, at your desktop resolution.
- **Windowed:** DayZ opens in a window of the size you pick (common sizes in a list, or type your own).

The launcher sets this in DayZ's own settings file each time it starts DayZ. Only the display mode and window size are changed, and your original file is kept as `DayZ.cfg.mmlauncher-backup`.

## New: import and export mod lists
Works with the official DayZ launcher's preset files, both ways.
- **MODS > Import list…:** pick a preset from the DayZ launcher or MM Launcher (or a text file of Workshop links or IDs). The launcher offers to download whatever's missing, and remembers the list so "Remove unused" never deletes its mods. Each imported list gets its own entry in the filter; **Forget this list…** lets it go.
- **MODS > Export shown…:** saves the mods on screen (after any search or filter) as a preset file.
- **Export list…** on a server's mod list saves that server's mods, in load order. Handy for sharing a modpack or loading it in the DayZ launcher.

- **MMLauncher.exe**: the same launcher as a single portable file.

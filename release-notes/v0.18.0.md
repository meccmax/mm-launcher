## New: MM Launcher on your Discord profile
While the launcher is open, Discord shows **Playing MM Launcher** with the MM logo and what you're up to:
- "Browsing servers"
- "Playing on MM Deer Isle | PvE…" with a timer (other servers just show "a community server")
- "In the DayZ Editor"

Your friends get buttons to **Get MM Launcher** and **Join Misfit Mercenaries**. Don't want it? Untick **Settings > Show what I'm playing on Discord**.

## New: fixes a common DayZ start-up error
If DayZ stops at start with *"File …DayZProfile, line 0: … encountered instead of '='"*, its settings file got damaged (usually by a crash, or OneDrive syncing while DayZ was saving). The launcher now spots this before starting DayZ and offers to **fix it**: it renames the damaged file (nothing is deleted) and DayZ makes a fresh one. You'll need to set your video and audio options again; key bindings are kept.

- **MMLauncher.exe**: the same launcher as a single portable file.
- **MMServerAgent.zip**: for MM server admins. See `AGENT-SETUP.txt` inside. (No agent changes in this version, apart from the new icon.)

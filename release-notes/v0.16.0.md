## Server admins: MM BlackBox stats for the website leaderboards
This release only changes the server agent. There's nothing new in the launcher for players.

The MM website's leaderboards (AI kills, travel, longest shot and more) come from each DayZ server's MM BlackBox stats file. The agent can now hand that file to the website:
1. Run **update-agent.bat** as administrator.
2. Run **stats-token.bat** as administrator. It makes a password, saves it in `agent.jsonc` (new `"BlackBoxStatsToken"` option) and restarts the agent.
3. Put that password in the website repo's `BLACKBOX_TOKEN` secret on GitHub.

**check-agent.bat** now shows, for each server, whether its stats file was found.

It's off until a password is set. When on, only the files `public_stats.json` and `public_stats_season_<id>.json` in each server's `<profiles>\MM_BlackBox\Stats` folder can be fetched. They can only be fetched over an encrypted connection and only with the password. 10 wrong passwords in an hour block that address for the hour. Nothing else on the machine is reachable, and nothing changes for launchers or players.

## Downloads
- **MMLauncher-Setup.exe**: the launcher for players, installed with shortcuts. Updates itself in one click.
- **MMLauncher.exe**: the same launcher as a single portable file.
- **MMServerAgent.zip**: for MM server admins. See `AGENT-SETUP.txt` inside.
- **SHA256SUMS.txt**: checksums the launcher and agent use to verify updates.

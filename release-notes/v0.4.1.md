Security update for the **MM Launcher** and the **MM Server Agent**, following a full security audit. Every finding is listed in [docs/SECURITY-AUDIT.md](https://github.com/meccmax/mm-launcher/blob/main/docs/SECURITY-AUDIT.md).

## Players
Nothing changes in how you use the launcher. It updates itself to this version in one click.
- Updates must come from this project's GitHub page and pass a checksum check. Links the launcher opens are limited to GitHub and Steam.
- Server replies are size-checked, so a fake or broken server can't freeze the launcher.
- Server passwords are now fully hidden in the launcher log, even with spaces or quotes.

## Server admins
After updating, run **update-agent.bat** as administrator once (or install-agent.bat). This applies the new protections:
- the agent folder is locked to Administrators, SYSTEM and you, which keeps the Discord webhook private
- the service runs with only the Windows privileges it needs (`install --full-privileges` brings back the old behaviour if needed)
- problem reports are rate-limited before they're received, only files the launcher makes are accepted, and Discord posts can't ping anyone or carry clickable links

## Downloads
- **MMLauncher.exe**: the launcher for players. Windows may show "Windows protected your PC" because the exe isn't code-signed yet: click **More info**, then **Run anyway**.
- **MMServerAgent.zip**: for MM server admins only. See `AGENT-SETUP.txt` inside.
- **SHA256SUMS.txt**: checksums the launcher and agent use to verify updates.

## New: save server passwords
- **Show the password** while typing it: the password box has a **Show** button, so you can check for typos before joining.
- **Remember this password on this PC:** tick it when joining and JOIN SERVER won't ask again for that server.
- **View, change or forget it:** a passworded server's panel shows "Password saved on this PC" with **Show**, **Change** and **Forget**. No password saved yet? Click **Save password…**.
- **Kept safe:** saved passwords are encrypted with Windows' own protection for your Windows account, so only you, on your PC, can read them. They're never logged, never included in problem reports and never sent anywhere except to DayZ when you join.

If a server's password changes, use **Change** to update it.

## Fixed: "Unable to locate a running instance of Steam"
DayZ shows this when Steam and MM Launcher run at different permission levels, for example Steam set to "Run as administrator" and the launcher not, or the other way around. Windows keeps them apart, so DayZ can't reach Steam.

The launcher now checks for this before starting DayZ and tells you which one to restart and how. **Start anyway** is there in case the check gets it wrong.

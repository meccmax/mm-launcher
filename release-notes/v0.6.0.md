## New: browse every DayZ server
The server list now has four tabs:
- **MM servers:** our servers, same as before.
- **All servers:** every public DayZ server.
  - **Search** by name, map or IP address.
  - **Filter** by map (with how many servers run it), 1PP or 3PP, modded or vanilla, and hide empty or full servers.
  - **Sort** by players, name, map or lowest ping.
- **Favorites:** click **☆ Favorite** on any server to keep it here.
- **Recent:** the last 25 servers you joined.

Pick a server in any tab and you get the same details panel as MM servers: the full mod list, **JOIN SERVER** with automatic mod downloads, Verify files, Repair and auto-rejoin. Vanilla servers with no mods work too.

## Server admins
The "All servers" list comes from Valve through the MM Server Agent, using a free Steam Web API key that stays on the server.
1. Run **update-agent.bat** as administrator.
2. Get a key at https://steamcommunity.com/dev/apikey (the Steam account needs $5 spent).
3. Paste it into `agent.jsonc` as `"SteamWebApiKey"`, then restart the service. One agent with a key is enough. Full steps are in `AGENT-SETUP.txt`.

Until a key is set, the "All servers" tab says no list is available. Everything else works as before.

## Downloads
- **MMLauncher.exe**: the launcher for players. Updates itself in one click.
- **MMServerAgent.zip**: for MM server admins. See `AGENT-SETUP.txt` inside.
- **SHA256SUMS.txt**: checksums the launcher and agent use to verify updates.

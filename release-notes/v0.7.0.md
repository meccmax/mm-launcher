## New: restart warnings
MM servers now show when they restart next:
- A **NEXT RESTART** tile on each server ("in ~1h 52m").
- **"restart ~8 min"** in the server list when a restart is close.
- An orange **warning** when a restart is under 15 minutes away.
- If you click JOIN within 5 minutes of a restart, the launcher **asks first**, so you don't load in just to get kicked.
- **Auto-rejoin** knows about restarts: if you get dropped right at restart time, it waits for the server to come back, then rejoins after a short random delay.

"~" means the time is estimated from when the server last started (our servers restart every 4 hours).

## Server admins
1. Run **update-agent.bat** as administrator.
2. In `agent.jsonc`, set `"RestartEveryHours": 4` (or fixed times with `"RestartTimes"`).
3. Restart the service.

Each server can have its own schedule. See `AGENT-SETUP.txt`.

Also: the agent's note about the all-servers list being too large for Steam to send completely is now a once-a-day "Note" instead of a "Warning". Every server with players is always included.

## Downloads
- **MMLauncher.exe**: the launcher for players. Updates itself in one click.
- **MMServerAgent.zip**: for MM server admins. See `AGENT-SETUP.txt` inside.
- **SHA256SUMS.txt**: checksums the launcher and agent use to verify updates.

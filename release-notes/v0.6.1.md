## Fix: All servers now really lists all of them
Valve sends at most 10,000 servers per request, and DayZ has more than that. So v0.6.0 showed an arbitrary slice of the list, mostly empty servers, and many populated servers were missing. The agent now asks for the list in parts (servers with players, empty servers, and each part split by map if needed) and combines them.

## Server admins
Run **update-agent.bat** as administrator on the agent that has the Steam Web API key. Nothing else to change.

## Players
The launcher updates itself as usual. The only change on your side is a clearer tooltip on the 1PP/3PP filter. The full server list arrives once the agent is updated.

## Downloads
- **MMLauncher.exe**: the launcher for players.
- **MMServerAgent.zip**: for MM server admins. See `AGENT-SETUP.txt` inside.
- **SHA256SUMS.txt**: checksums the launcher and agent use to verify updates.

## New: player history
MM servers now have a **PLAYERS** tab with a chart of how many people were on:
- Switch between the **last 24 hours** and the **last 7 days**.
- See the peak, the average, and when the server is **usually busiest**.
- Hover the chart to see the exact count at any time. Grey bands show when the server was restarting or down.

## Server admins
Run **update-agent.bat** as administrator. The agent then records each server's player count every 5 minutes (kept for 7 days in `player-history.jsonc`). The PLAYERS tab appears in launchers after the first reading, and the chart fills in over the following days.

## Downloads
- **MMLauncher-Setup.exe**: the launcher for players, installed with shortcuts. Updates itself in one click.
- **MMLauncher.exe**: the same launcher as a single portable file.
- **MMServerAgent.zip**: for MM server admins. See `AGENT-SETUP.txt` inside.
- **SHA256SUMS.txt**: checksums the launcher and agent use to verify updates.

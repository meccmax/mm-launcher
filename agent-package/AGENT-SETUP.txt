MM SERVER AGENT - SETUP (one-time per server machine)
=====================================================

What it does
  Watches the DayZ servers running on this machine (the ones CFTools starts)
  and tells the MM Launcher each server's complete client mod list, full name,
  uptime and an optional message for players. It only reads: it never changes
  server files and never touches CFTools.

How it knows the mods
  It reads each running DayZServer_x64.exe's own startup line (-mod=, -config=,
  -port=) and the meta.cpp inside each mod folder (publishedid = workshop ID).
  Server-side mods (-servermod=) are NOT reported. Passwords are never read
  out or sent anywhere.


SETUP
-----
1. Copy this whole folder somewhere permanent on the server machine,
   e.g.  C:\Apps\MMServerAgent

2. Double-click check-agent.bat.
   You should see every running DayZ server with its ports and full mod list.
   If it says it can't read a startup line, right-click check-agent.bat and
   "Run as administrator".
   (The first run also creates agent.jsonc next to the exe.)

3. Pick this machine's port.
   One machine: leave it at 2999.
   Several machines behind the same public IP: give each its own port
   (2999, 2998, 2997, ...). Edit "Port" in agent.jsonc. The launcher checks
   2994-2999 out of the box.

4. Right-click install-agent.bat > Run as administrator.
   This installs the "MM Server Agent" Windows service (starts with Windows,
   auto-restarts) and opens the port in Windows Firewall.

5. On your router, forward TCP <that port> to this machine.

6. Test from any PC outside your network (or your phone on mobile data):
      http://game.misfitmercenaries.com:2999/
   You should see a short text page listing the servers.
   Then open the MM Launcher: the bottom bar says "1 MM agent connected" and
   each server's mod list shows "VERIFIED BY MM AGENT".


PROBLEM REPORTS -> DISCORD
--------------------------
Players can click "Report a problem" in the launcher. It bundles their latest
DayZ logs, crash info, the server's mod list and PC basics, and sends it here.
Every report is saved in the "reports" folder next to the exe (oldest deleted
past KeepReportsMB). To also post them to a staff channel:

1. In Discord: make the channel (staff-only), then Edit Channel > Integrations
   > Webhooks > New Webhook. Name it "MM Launcher" and copy the Webhook URL.
2. Open agent.jsonc and paste it into "DiscordWebhookUrl" (inside the quotes).
3. Restart the service: services.msc > MM Server Agent > Restart.
4. Check http://<this machine>:2999/  ->  it should say "Problem reports: on (Discord)".

Each post shows player, server, the crash reason pulled from the logs, error
codes, PC info and a reference number, with the zip attached. Posts can't ping
anyone (@everyone/@here are ignored). Limits: MaxReportsPerHourPerAddress,
MaxReportsPerDay, MaxReportMB (Discord's own cap is 10 MB). Keep the webhook URL
private - anyone who has it can post to that channel. If it ever leaks, delete
the webhook in Discord and make a new one.

To switch reports off: "AcceptReports": false.


OPTIONAL: names and messages
----------------------------
In agent.jsonc, under "Servers", add an entry per GAME port (-port=):

    "2902": { "DisplayName": "MM Deer Isle", "Message": "Wipe Saturday, Badlands drop!" }

Save, then restart the service (services.msc > MM Server Agent > Restart).


UPDATING THE AGENT
------------------
The agent never updates itself. check-agent.bat tells you when a newer version
is out. To install it: right-click update-agent.bat > Run as administrator.
It downloads the new version from github.com/meccmax/mm-launcher, checks it
against the published checksum, stops the service, swaps the exe and starts it
again. agent.jsonc, agent.log and the reports folder are left alone.


DAYZ EDITOR PRESETS (v0.8 and newer)
------------------------------------
The launcher has a DAYZ EDITOR page that starts DayZ offline with CF, Dabs
Framework, DayZ-Editor and a preset of mods. To share MM presets with your admins:
  1. In the DayZ launcher, set up the mods (map and building mods, in load order)
     and use Mods > Presets > Export to save it as an .html file. A .txt file with
     one Steam Workshop ID or link per line works too.
  2. Put the file in the "editor-presets" folder next to MMServerAgent.exe (the
     agent makes the folder, with a README, the first time it starts).
Every launcher then lists it under EDITOR PRESETS as "shared by MM" (read-only;
players click Copy to make their own version). The file name is the preset name,
unless the .html has its own. Changes show up without restarting the agent.
CF, Dabs Framework and DayZ-Editor are always loaded first; no need to list them.


RESTART SCHEDULE (v0.7 and newer)
---------------------------------
Tell the agent when your servers restart and the launcher shows players "Next
restart: in ~1h 52m", warns when a restart is under 15 minutes away, asks before
joining a server that restarts within 5 minutes, and auto-rejoin waits for the
restart instead of reconnecting just before it.
In agent.jsonc, use ONE of:
  "RestartEveryHours": 4,               restarts every 4 hours counted from when each
                                        server started (CFTools / BattlEye schedules)
  "RestartTimes": ["00:00", "04:00"],   fixed clock times, this machine's time zone
A server with a different schedule can override it in its "Servers" entry, e.g.
  "2302": { "DisplayName": "", "Message": "", "RestartEveryHours": 6 }
Then restart the service. With RestartEveryHours, a manual restart starts the count
over, so the launcher marks those times as approximate ("~").


SERVER BROWSER FEED (v0.6 and newer)
------------------------------------
The launcher's "All servers" tab lists every DayZ server. That list comes from
Valve, through this agent, using a Steam Web API key that stays on this server.
One agent with a key is enough; give it to more than one for backup.
  1. Sign in at https://steamcommunity.com/dev/apikey (the Steam account needs
     at least $5 spent on Steam). Domain name: anything, e.g. misfitmercenaries.com.
  2. Copy the key into agent.jsonc: "SteamWebApiKey": "YOUR-KEY-HERE"
  3. Restart the service (services.msc > MM Server Agent > Restart).
agent.log then shows "Server browser feed: N DayZ servers from Steam". The list is
refreshed every 5 minutes ("ServerListRefreshMinutes") and saved as
server-list-cache.json.gz so a restart serves it straight away.
Keep the key secret: anyone with it can use your Steam Web API quota. If it ever
leaks, revoke it on the same page and make a new one.
The same key also powers the launcher's Friends tab (which Steam friends are playing
DayZ, and where) and its Workshop search on the MODS page. Friends lookups are
cached for a minute, Workshop searches for 5 minutes, and both are limited per
address.


ENCRYPTION (v0.5 and newer)
---------------------------
The agent encrypts what it sends to launchers (mod lists and problem reports). It
makes its own key the first time it starts and keeps it in agent-tls.pfx. Nothing
to set up, but:
  * Keep agent-tls.pfx. It's how launchers recognise this agent. If it's deleted, a
    new key is made and launchers will refuse the agent until the fingerprint below
    is updated. Copy it along if you ever move the agent to another folder or PC.
  * check-agent.bat shows "Encryption key fingerprint: ...". Send that line, with the
    address and port players use (e.g. game.misfitmercenaries.com 2999), to whoever
    maintains the launcher, so it goes in the published list of official agents.
  * agent.jsonc "AllowPlainHttp": true still answers launchers older than v0.5.
    Set it to false once players have updated, then restart the service.


SECURITY
--------
install and update lock the agent folder so only Administrators, SYSTEM and
you can read or change it (agent.jsonc holds the Discord webhook). Keep the
agent in a folder of its own, e.g. C:\Apps\MMServerAgent; if the folder holds
other files, the permissions are left alone and install tells you.

The service runs with only the few Windows privileges it needs. If check-agent.bat
shows it can't see your DayZ servers after installing, reinstall it with full
privileges: open an admin command prompt in this folder and run
  MMServerAgent.exe install --full-privileges

Upgrading from v0.4.0? Run update-agent.bat (or install-agent.bat) once so the
folder lock and reduced privileges are applied.

Report uploads are limited (3 per hour per address, 50 per day, 9 MB each) and
only the files the launcher itself makes are accepted. All limits are in
agent.jsonc. Full audit: github.com/meccmax/mm-launcher/blob/main/docs/SECURITY-AUDIT.md


FILES
-----
  MMServerAgent.exe    the agent
  agent.jsonc          settings (every option explained inside)
  agent-tls.pfx        the agent's encryption key (made on first start; keep it)
  server-list-cache.json.gz  last list of all DayZ servers (only with a Steam key)
  editor-presets\       DayZ Editor presets shared with every launcher (.html / .txt)
  agent.log            what it's doing; send this to Claude if anything's off
  reports\             problem reports players sent (zips)
  check-agent.bat      show what it sees right now
  install-agent.bat    install/reinstall the service (run as admin)
  uninstall-agent.bat  remove the service + firewall rule (run as admin)
  update-agent.bat     install the newest agent from GitHub (run as admin)
